## 2. Catalog audit — provenance, classification, links, claims

Counts were recomputed from `data/*.json`. Headline documentation numbers are **accurate**: `intelligence.json` has 561 records (281 courses, 22 universities, 25 professional, 23 scholarship, 24 opportunity, 100 project, 33 research, 33 pathway, 13 CV, 7 location); exactly 2 scholarship records have reviewed open-cycle evidence; 18 records remain in each review queue; `development.json` has 33 majors, 33 skill maps, 10 pathways and 516 editorial skills.

Confirmed defects (all reproducible from the files named):

1. **Stale derived record.** `data/opportunities.json:955` archives `ubc-international-scholars-2027`, but `data/intelligence.json:12947-13005` has no `archived` key, `status: "Deadline not announced"` and a past `finalDeadline: 2026-11-25`. The compile mapping at `scripts/compile-intelligence.mjs:71-86` should have produced `Previous cycle`. `tests/check-data.test.js:194-206` cannot see it because that file is not validated.
2. **11 confirmed deadlines labelled "Deadline not announced".** Example `data/intelligence.json:11714-11719` (`opportunity-rsi`, `finalDeadline 2026-12-11`, `dateStatus: "Confirmed deadline"`). Cause: blanket status mapping at `scripts/compile-intelligence.mjs:80-84` ignores `deadlineConfirmed`.
3. **Data gate covers 3 of 8 seed files.** `scripts/check-data.js:287-294` loads only `opportunities.json`, `resources.json`, `development.json`; `intelligence.json`, `curated-intelligence.json`, `learning-resources.json`, `feed-snapshot.json` and `project-blueprints.json` are unvalidated, contradicting `docs/maintenance.md:19`.
4. **`approvedSources` is a mislabel.** `api/admin.js:89` reports `sourceRegistry().length`, but `lib/intelligence-data.js:11-38` builds that registry mechanically from every record URL. No record has `approvedBy`, `reviewedBy`, `rights` or `license`.
5. **Feed metadata inconsistent.** `data/feed-snapshot.json:6` and `lib/feeds.js:296` say "Monday mornings"; `api/refresh.js:20-22` refreshes daily. Snapshot is dated 2026-11-06.
6. **Header date precedes records.** `data/intelligence.json:3` says `checkedOn: 2026-11-12` while three records carry later dates (including 2026-11-24).

Checked and **not** found: duplicate IDs within any file; non-HTTPS or malformed URLs (2,246 URLs, 0 invalid); impossible dates; other unarchived past deadlines in `opportunities.json`. A 10-URL `curl.exe` sample returned HTTP 200 for eight, and Cloudflare 403 challenges (inconclusive, not dead links) for two Lumière URLs. Two claim spot-checks matched their sources; the Yenching page returned garbled content, so its deadline was **not** verified. A full 2,246-URL liveness sweep and exhaustive claim-to-source audit were not performed.

## 3. BARYS and ProspectoAI — independent evaluation

They are distinct: **BARYS** is a deterministic, local navigation router (`src/barys.js:37`, `src/guide-intent.js:7-8,113`, no model call); **ProspectoAI** is the signed-in model assistant behind `api/chat.js`, `api/coach.js` and `api/development.js`, routed through `lib/ai-gateway.js:229` or `lib/direct-provider.js:26`.

Already tested at the reviewed baseline: signed-out 401 before payload work (`tests/api-errors.test.js:79-117`, live probe in `check-live.js:82-92`); malformed input 400 (`:119-136`); provider failure 503 with catalog fallback (`:170-188`); gateway fallback rules (`tests/ai-gateway.test.js:95-226`); BARYS unknown-intent fallback (`tests/guide-intent.test.js:26`).

Gaps identified at baseline:

- **"Source-grounded" was enforced at input only.** Evidence is retrieved and serialized (`api/chat.js:84-102,175-182`), but `references` are derived from retrieved records (`api/chat.js:131-137`) and printed as a separate link strip (`src/platform.js:485-497`). No code parsed model text to verify that named programmes, dates or eligibility matched those records. This is evidence adjacency, not claim-level verification.
- **No contradictory-source handling** despite `dateStatus` conflict values (`data/opportunities.json:262,489`) and no test asserting expired/archived rows are excluded from AI evidence (the filtering itself exists at `lib/assistant.js:18-24,45-48,74-77`).
- **No AI out-of-scope refusal test** (only BARYS has one), **no 502 path** (grep found zero `502` in source/tests/docs; failures normalize to 503), and no coach/plan-draft provider-failure tests (`api/coach.js:107-118`, `api/development.js:125-137`).
- **Live generation remains unverified**, as `docs/release-status.md:50,67,77,87,95,121` already states. No live AI success is claimed here.

During this session a separate process added `lib/grounding.js`, `tests/ai-grounding.test.js`, `tests/chat-grounding.test.js` and modified `api/chat.js` / `api/coach.js` to address several of these gaps. Those edits are **in the uncommitted tree and are not part of this audited baseline**.

## 4. Accounts, ownership, private documents, deployment

Implemented and tested at baseline: guest gating and safe return (`src/access.js:10-27`, `src/auth-flow.js:4-20`); unit tests for signup copy, callback/return paths, recovery help, public projection and document extraction (`tests/auth-signup.test.js`, `tests/auth-flow.test.js`, `tests/auth-help.test.js`, `tests/public-discovery.test.js`, `tests/workspace.test.js:141-215`). No signed-in email-change or password-change form exists; the only `updateUser` call is in recovery (`src/auth-page.js:163`).

RLS ownership policies exist across migrations (trackers/activities, profiles, nine workspace tables, document path-prefix constraint, admin role, atomic review RPC, private Storage bucket). Two isolated-identity rollback SQL suites exist (`tests/workspace-rls.sql`, `tests/intelligence-rls.sql`) but **no code or npm/CI step invokes them** — they are manual, owner-run artifacts. Applying them and confirming production policies requires live credentials; no account or identity was created.

Private CV/portfolio controls are implemented (owner-prefixed Storage paths, DB row after upload with rollback, server extraction scoped by `id` + `user_id`, 60-second client-side signed download, public projection denylist at `lib/public-catalog.js:1-54`). No live secret values or private document text were found in tracked files. One real personal email literal is hard-coded as an admin bootstrap in `supabase/migrations/20261111184311_prospectoai_intelligence_workspaces.sql:5` — flagged as PII/human decision; an applied migration was **not** rewritten.

Two small verified defects were fixed in this session: `.vercelignore` now excludes `.env`, `.env.*` and `.vercel` (previously a CLI deploy could ship a local `.env.local`); and the vacuous CI step `git diff --exit-code -- dist/data.js` (the file is untracked and absent by design) was replaced with `test ! -e dist/data.js && echo 'PASS: no generated catalog file in dist'`, with `CONTRIBUTING.md` and `docs/verification.md` updated. Stale claims in `docs/auth-verification.md` (206 tests, pre-#15 production build) were corrected by an appended dated note; `docs/recovery.md` now points password-recovery readers to the auth docs. `docs/plan/strategy.md` has an appended correction that `ignoreCommand` was removed (D-05). A blank pilot record sheet was added at `docs/pilot-record-sheet.md`.

## 5. Performance and accessibility

Measured from local `dist/`: 25 files, 921,228 bytes; JS 719.6 KiB, CSS 144.1 KiB. Deployed wire sizes were measured with `curl.exe --compressed`: `/api/catalog` **166,133 B Brotli / 2,360,836 B raw**, fetched `no-store` on every public load (`src/bootstrap.js:34,63`); `bootstrap.js` ~75 KB Brotli; ten CSS requests total 30,339 B. `dist/index.html:22-33` has ten render-blocking stylesheets and a parser-blocking `theme.js`; `src/bootstrap.js:120-126` loads four view scripts sequentially. No network throttling, Lighthouse trace, FCP/TTI measurement or real-device run was performed — those targets remain human-only. A concurrently added `scripts/perf-check.js` uses Playwright-core/CDP throttling; it was not validated as part of this audit.

Accessibility is substantially implemented (skip link, single `h1`, landmarks, route announcer, native dialogs with focus return, mobile drawer focus trap, focus-visible rules, reduced motion, forced colors). Concrete gaps: `role="menu"` without Arrow/Home/End model (`dist/index.html:154-161`, `src/platform.js:210-224`); `aria-label` on role-less generic divs (`dist/index.html:202,406,504-508`); programmatic focus lands on `<main>` whose outline is removed (`dist/theme.css`/`dist/platform.css:1258`); contrast tests cover dark tokens only (`tests/theme-contrast.test.js:9-31`). Screen-reader, 200% zoom and 320 px verification remains human-only (`docs/accessibility.md:43-48`).
